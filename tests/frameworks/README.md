# Slice (Nexus-JS) — Real-World Framework Test & Benchmark Suite (`tests/frameworks/`)

This directory houses full-stack framework integration tests and cross-runtime benchmarks comparing **Slice (`v0.9.2`)**, **Bun**, **Deno**, and **Node.js** on modern Edge and WinterTC frameworks (such as **Hono**, **itty-router**, **UnJS / Nitro (`ufo`, `destr`, `ohash`, `radix3`)**, and **JSX/TSX SSR**).

General multi-file application and security benchmarks (`01-fintech-checkout` through `24-tsx-ssr-and-wasm-edge-pipeline`) are located in [`../apps/`](../apps/).
